Le montant de base du tarif en Ariary
Laissez vide ou mettez 100 pour appliquer 100% du montant de base
Calcul du montant final: Si vous entrez un pourcentage, le montant final sera calculé comme: montant_base × pourcentage ÷ 100
Retour
Aide
  • Un tarif associe un type de personne (Adulte, Enfant, etc.) à un type de siège (Normal, VIP, etc.)
  • Le montant de base est le prix initial
  • Le pourcentage permet d'appliquer une réduction ou majoration sur le montant de base
  • Exemples:
    • 100% = prix normal
    • 50% = moitié prix (réduction)
    • 150% = prix majoré de 50%
